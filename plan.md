# Sales Dashboard — План проекта

## Цель

Заменить Power BI на современный Streamlit-дашборд с доступом по ссылке для команды (2-10 человек). Данные из Google Sheets, обновляемых раз в неделю.

## Модель данных

Три Google Sheets, связанные через поле **ID**:

```
excel_sale_2025 (главная таблица)
├── id                  — уникальный идентификатор товара (например т127390045)
├── наименование        — название товара
├── дата продажи        — дата в формате DD.MM.YYYY
├── наценка             — валовая прибыль (продажа - себестоимость)
├── себестоимость        — закупочная цена (COGS)
├── витрина             — витринная цена
├── продажа             — цена продажи (Revenue)
├── подкатегория        — Ювелирные изделия, Телефоны, Ноутбуки, Smart часы, Аксессуары, Другое
├── состояние           — Продан
├── отделение           — L'amour, L'amour NEW, ReTech, Ком. магазин, Service и др.
└── комментарий         — заметки продавца

excel_employee_2025 (кто продал)
├── Дата, время записи  — дата и время продажи
├── Операция            — "Продажа товара"
├── ID                  — связь с excel_sale_2025
└── Сотрудник           — ФИО сотрудника

excel_source_2025 (откуда товар)
├── Дата, время записи  — дата и время
├── ID                  — связь с excel_sale_2025
└── sourse              — "скупка" или "вывод из залога"
```

### Связи (JOIN по ID)

```
excel_sale_2025.id = excel_employee_2025.ID  → добавляет колонку "сотрудник"
excel_sale_2025.id = excel_source_2025.ID    → добавляет колонку "источник"
```

### Вычисляемые метрики

- **Выручка** = сумма(продажа)
- **Себестоимость (COGS)** = сумма(себестоимость)
- **Валовая прибыль** = сумма(наценка)
- **Маржа %** = наценка / продажа × 100
- **Средний чек** = сумма(продажа) / кол-во строк

## Архитектура

```
Google Sheets (3 таблицы)
    ↓ публичный CSV-экспорт (без API-ключей)
pandas read_csv (dtype=str, для корректного парсинга чисел)
    ↓ JOIN по ID, очистка числовых полей
Единый DataFrame
    ↓
Streamlit Dashboard (5 страниц + фильтры в сайдбаре)
    ↓ деплой
Streamlit Cloud → https://sales-dashboard-99pkhd3rtquur6rxsfmzuh.streamlit.app/
```

## Структура дашборда

### Страница 1: Обзор
- 6 KPI-карточек: Выручка, Себестоимость, Валовая прибыль, Средний чек, Кол-во продаж, Маржа %
- Дельта vs прошлый период
- Линейный график выручки (по месяцам/неделям/дням)
- Графики прибыли и количества
- Авто-инсайты (сравнение с прошлым месяцем, предупреждения по марже)
- Сводная таблица по годам (как в Power BI)
- Детализация по месяцам
- Экспорт в PDF

### Страница 2: Филиалы
- Bar chart выручки по отделениям
- Маржа и количество по отделениям
- Тепловая карта: Филиал × Месяц
- Динамика выбранных филиалов (line chart)
- Детальная таблица

### Страница 3: Категории
- Donut chart долей категорий
- Bar chart выручки по категориям
- Маржинальность и количество
- Динамика по категориям (line chart)
- Топ-15 товаров в выбранной категории
- Сводная таблица

### Страница 4: Сотрудники
- Рейтинг топ-15 (по выручке / по количеству / по марже)
- Профиль сотрудника: KPI-карточки, график выручки, donut по категориям
- Сводная таблица

### Страница 5: Сравнение и прогноз
- Алерты (падение выручки филиала >15%, маржа ниже 20%)
- Сравнение месяц к месяцу (MoM): KPI + bar chart по филиалам и категориям
- Сравнение год к году (YoY): наложение месяцев + таблица изменений
- Линейный прогноз на 1-6 месяцев (выручка, прибыль, количество)

### Фильтры (сайдбар, влияют на все страницы)
- Период (date range + быстрые кнопки: Всё / Этот год / Квартал / Месяц / Неделя)
- Филиал (мульти-выбор)
- Подкатегория (мульти-выбор)
- Источник (скупка / вывод из залога)
- Сотрудник (мульти-выбор)
